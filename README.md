# AWS EC2 Setup and Cloud Server Launch (Class 1)

## What I did
- Created an AWS account
- Launched an Ubuntu EC2 instance (t3.micro, ap-southeast-2)
- Configured security group (SSH 22, HTTP 80)
- Connected using EC2 Instance Connect
- Installed Nginx and deployed a simple website
